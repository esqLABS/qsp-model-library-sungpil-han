## What the literature does **not** anchor

Set down honestly. The following values were measured directly nowhere in the literature above; they
are **constructs** settled while calibrating the model output.

| Parameter | Value | Character |
|---------|-----|------|
| `TEAR_TH` (critical stress-impulse for propagation) | 0.45 | the **existence** of a threshold carries a large part of the acute-mortality comparison. No value has been measured in humans |
| `TAUFL0` (reference RC time constant of the false lumen) | 0.30 s | the **form**, a low-pass filter, is physically right but the constant is a calibrated value |
| `GRE0` (re-entry conductance) | 0.05-2.4 | a dimensionless number set by mapping onto clinical phenotypes; it has no measured units |
| `KGROW` (growth gain) | 3.55e-4 mm/h | fitted to 3.96 mm/year for a patent false lumen |
| `KTHR_H` (wall thinning under thrombus) | 1.0 | wall thickness halved at complete thrombosis. The same magnitude as the 25-50% thinning in the AAA literature, but not a value measured directly in dissection |
| `KH_EXT` (propagation hazard coefficient) | 4.0e-3 | fitted to an untreated 72-hour mortality of 2.3% |
| `KCOLL`, `KCOL_SPI` (collateral recruitment) | 0.02/h, 0.85 | the concept is Griepp/Etz, the rate constants are calibrated |
