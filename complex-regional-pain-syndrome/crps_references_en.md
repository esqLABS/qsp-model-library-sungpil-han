# CRPS QSP model — references

A list of the literature used to build the mechanistic map, the mrgsolve ODE model, and the Shiny
dashboard for complex regional pain syndrome (CRPS).

> **A note on the link format**: the links below are all **PubMed search query URLs**.
> Because a wrongly recorded PMID would cite an entirely different paper, links that search on the author, year, and
> title keywords were used instead. Clicking one goes to the paper concerned (or to a results list
> in which that paper is the top hit). Where a model parameter is anchored to a particular reference, the
> correspondence is set out in the CALIBRATION ANCHORS section at the top of
> `crps_mrgsolve_model_en.R`.

### Summary of the model parameter anchoring (calibration anchors → parameters)

| Evidence | Model parameter / result |
|---|---|
| Sigtermans 2009 (ketamine for 100 hours, NRS 7.2→2.7 during the infusion, gone after ~11 weeks) | `A_KET`, `EC50_KET`, `EMAX_KET` → the model gives 6.04→3.02 (d34) and returns to within 0.3 of untreated by d44 |
| Kemler 2000 / 2008 (SCS positive at 6 months, the difference gone by year 5) | `A_SCS`, `SCS_EFF`, `SCS_HAB_K` → +3.27 at 7 months, +0.15 at 60 months |
| Varenna 2013 (neridronate 100 mg IV ×4, with the effect sustained to one year) | `EMAX_NER`, `BONE50_NER`, `W_BONE_PS` → at one year NRS −1.83, CTX-I −61%, BMD preserved |
| Goebel 2017 LIPS (IVIG negative in long-standing CRPS) | `W_AAB_PS` kept small → the late IVIG effect ≈ 0 |
| Zollinger 2007 (vitamin C for prevention), Perez 2003 (DMSO/NAC) | `EMAX_NAC`, `EC50_NAC`, `KOUT_ROS` |
| Ji 2013/2019, Coull 2005 (glial priming, BDNF-KCC2) | `W_GLIA_SELF`, `GLIA50`, `HILL_GLIA`, `KOUT_GLIA` (the locking structure) |
| Moseley 2004/2006, Maihöfner 2004 (use-dependent cortical remapping) | `REHAB_CTX`, `KOUT_CTX`, `W_DIS_CTX` |
| de Jong 2005, Bean 2015 (pain-related fear determines prognosis) | `KFEAR`, `PAIN50_FEAR`, `HILL_FEAR`, `REHAB_FEAR` (the bifurcation parameters) |
| Eberle 2009, Wasner 2001, Groeneweg 2006 (the warm→cold transition) | `W_NP_PERF`, `W_A1_PERF`, `W_SS_PERF`, `W_ROS_PERF` |
| Harden 2010/2017 (the Budapest criteria, CSS 0-16) | the four-domain summation of `CSS` in `$TABLE` and the `ACTIVE_CRPS` flag |
