# Full per-model compound perturbation census (all 415 models, 1,458 compounds)

Generated by a calibrated Python classifier that scanned every
`*/*_mrgsolve_model.R` file for each drug's own PK-derived concentration
variable, and classified how it could be redirected to an externally-supplied
covariate (see `../../ESQlabs_curation_and_extension.md` and the pilot plan
this table was produced for). The classifier reproduced all 6 hand-verified
ground-truth files exactly before being trusted at this scale.

**Known limitations, read before using this table for anything beyond
triage:**
- A second, independent reimplementation of this same classifier produced
  materially different aggregate totals in the long tail beyond the 6-file
  calibration set (most notably on `delete_compartment` classification and
  overall per-file detection rate), despite both matching the calibration
  set exactly. Treat individual row classifications as a strong first pass,
  not ground truth — especially near category boundaries.
- Target/Pathway is genuinely unknown (`?`) for roughly 70% of compounds —
  the lookup dictionary only covered a minority of the ~1,450 distinct drug
  names found across the corpus. `?` means "not determined," never a guess.
- A few duplicate rows exist where the same compound was independently
  detected twice within one file (e.g. `visceral-leishmaniasis | Miltefosine`,
  `chagas-disease | Nifurtimox and fexinidazole`) — worth a quick manual check
  before treating them as two separate targets.

Last three columns are intentionally blank placeholders for manual
annotation (e.g. target compartment, expected unit, status), sorted by
disease directory then compound name.
